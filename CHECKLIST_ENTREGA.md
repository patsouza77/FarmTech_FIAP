# Checklist final da entrega

## Identificação e autoria

- [ ] Substituir os nomes e RM no `README.md`.
- [ ] Confirmar com o grupo a escolha de soja e milho.
- [ ] Todos os integrantes leram e conseguem explicar a parte que desenvolveram.
- [ ] O texto do resumo foi revisado pelo grupo com olhar crítico e autoral.

## Funcionamento

- [ ] `python -m unittest discover -s tests -v` mostra seis testes com `OK`.
- [ ] `python farmtech.py` permite cadastrar soja e milho.
- [ ] A opção 3 lista os dados e as posições do vetor.
- [ ] A opção 4 atualiza e recalcula um registro.
- [ ] A opção 5 exclui o registro escolhido.
- [ ] A opção 6 encerra o programa.
- [ ] `Rscript analise_estatistica.R` mostra média e desvio-padrão.
- [ ] `Rscript clima_api.R` exibe dados meteorológicos atuais.

## GitHub

- [ ] Repositório compartilhado com o grupo.
- [ ] Branches criadas para partes distintas.
- [ ] Commits significativos feitos pelas contas dos respectivos integrantes.
- [ ] Pull Requests abertos e revisados por outro integrante.
- [ ] Todos os Pull Requests necessários foram integrados na branch `main`.
- [ ] Versão final baixada da branch `main` para preparar a entrega.

## Resumo

- [ ] Máximo de uma folha A4.
- [ ] Fonte Arial 11.
- [ ] Espaçamento simples.
- [ ] Margens direita e esquerda de 2 cm.
- [ ] Arquivo aberto e conferido visualmente.

## Vídeo e ZIP

- [ ] Vídeo mostra o funcionamento completo do Python e do R.
- [ ] Vídeo tem no máximo cinco minutos.
- [ ] Vídeo foi publicado no YouTube como **Não listado**.
- [ ] Link real substituiu o marcador em `video_youtube.txt`.
- [ ] Link foi aberto em janela anônima e funciona.
- [ ] ZIP contém Python, R, resumo e TXT com o link do vídeo.
- [ ] ZIP foi descompactado uma vez para conferir se não está corrompido.
- [ ] Arquivo correto selecionado na plataforma antes da confirmação final.
